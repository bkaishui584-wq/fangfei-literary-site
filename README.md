# 芳菲文学社独立预览版

这是根据《最终版.docx》整理的独立前端原型，与 ProjectHub 完全分离。

## 已实现

- 首页、作品、作者主页、排行榜、文学活动
- 作品分类、搜索、阅读详情和评论
- 私信会话、未读状态、文字消息、回复、两分钟撤回、拉黑、举报和隐藏会话
- 通知中心
- 管理后台框架和 Agent 审核占位
- 原站六套主题、主题音乐播放器和可拖动桌宠
- 管理员公告发布、撤回与首页公告展示
- 月度优秀作品页面与编辑提名
- 浏览器 `localStorage` 数据保存

## 说明

当前版本是可交互 UI 原型，方便先确认信息架构和体验。正式版本仍需接入账号登录、服务端权限、数据库、真实审核 Agent、审计日志和内容持久化。
