# 芳菲文学社

芳菲文学社是一个独立运行的文学作品创作、阅读与交流平台，与 ProjectHub 分开。

## 当前功能

- 首页展示本月优秀、最新作品、热门作者、文学活动和文学社公告
- 作品分类、搜索、阅读详情、点赞、收藏、评论、分享、举报和私信作者
- 作者主页展示笔名、头像、简介、作品数量、月度优秀、点赞和总字数
- 私信会话、未读数量、文字消息、回复、撤回、拉黑、举报、隐藏会话和私信设置
- 通知中心与未读提示
- 投稿入口与作品标签
- 六套主题，入口位于“我的 > 设置”
- 管理员按角色显示管理入口，可维护作品视图、评论、举报、月度评选、活动、公告、Agent 审核状态和日志
- 可拖动桌宠

## 数据与权限

当前版本是纯静态前端，业务数据保存在浏览器 `localStorage`。仓库没有服务端登录、会话、数据库或管理 API，因此前端角色判断不能替代生产环境的后端权限控制。

管理员入口默认隐藏。要上线真实权限、跨设备数据同步和持久化管理，需要接入服务端认证、角色校验、数据库和接口权限。

## 音乐说明

音乐文件仍保留在 `assets/music/`，首页没有加载空播放器。以后有完整真实的音乐数据时再恢复音乐模块。
